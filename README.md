\# Retail Sales and Inventory Copilot



\## What it does



The Retail Sales and Inventory Copilot helps small retail-store managers

understand sales and inventory using natural-language questions.



The system provides:

\- Stock-out risk detection

\- Overstock detection

\- Top-selling product analysis

\- Sales spike/drop detection

\- Evidence-based recommendations

\- Gemini-powered answers grounded in verified retail data



The application uses deterministic analytics to calculate sales and

inventory figures. Gemini is then used to reason over the verified data

and present the results in a manager-friendly format.
